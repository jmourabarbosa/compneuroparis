Migrate Profile Images

This is a maintainer workflow for moving PI profile images from external URLs into the repository while keeping the existing photoURL field. Export the live manifest here, download the files locally with the Node script, then upload the generated mapping file back here to relink the affected profiles.

Step 2: Download images locally

Run this from the repo root after saving the exported manifest:

node tools/download-profile-images.mjs path/to/profile-image-manifest.json

The script downloads files into assets/profile-images/ and writes a companion mapping file ending in .downloaded.json.
